# <a name="up" />Проект 3-го спринта по ручному тестированию - тестирование учебного сервиса Яндекс Маршруты
Учебный сервис «Яндекс Маршруты» — это сервис, который строит маршруты для транспорта разных видов. Рассчитывает время и стоимость поездки. Чтобы построить маршрут пользователь вводит время отправления, улицу и номер дома. Пользователь может выбрать несколько режимов передвижения по маршруту: «Оптимальный», «Быстрый», «Свой».

## Задачи тестировщика

<details>
  <summary>Задачи проекта 3-го спринта</summary>
  
  #### Задачи
  1. Провести тест-анализ и декомпозицию требований к учебному сервису Яндекс Маршруты, подготовить чек-лист на вёрстку полей - форма бронирования; элементы на навигационной карте: это иконки автомобилей и действия с ними.
  2. Подготовить чек-лист и тест-кейсы на логику работы окон. Составить следующую тестовую документацию: чек-лист на логику окон «Способ оплаты» и «Добавление карты», тест-кейсы на кнопку «Забронировать».
  3. Протестировать приложение и завести баг-репорты

</details>
